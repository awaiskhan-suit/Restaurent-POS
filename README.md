# 🍽️ Restaurant POS System — Flutter

A modern and user-friendly **Restaurant Point of Sale (POS) System** developed using Flutter and Firebase. This mobile application helps restaurant administrators manage products, monitor sales, organize orders, and streamline daily restaurant operations through a single interface.

## 🚀 Project Overview

The Restaurant POS System is designed to simplify restaurant management by providing essential tools for product management, sales analytics, menu browsing, cart management, and order processing. Firebase Firestore is used to store and manage product and order data.

## ✨ Key Features

### 1. 🔐 Admin Authentication
- Admin account registration using name, email, password, and confirm password.
- Secure login using email and password.
- Forgot password functionality through an email-based password reset request.

### 2. 📦 Product Management
- Add products with name, price, category, description, and image.
- Store product information in Firebase Cloud Firestore.
- Edit existing product details.
- Delete products when required.
- Organize products by category for easier management.

### 3. 📊 Dashboard & Sales Analytics
- Display total orders and today's orders.
- Monitor total sales and today's sales.
- Track items sold today.
- Identify top-selling products.
- View key restaurant performance statistics in one place.

### 4. 🍔 Menu Management & Search
- Browse products across multiple categories:
  - Burgers
  - Pizza
  - Shawarma
  - Biryani
  - Cold Drinks
- View product images, names, prices, and descriptions.
- Search products by name.
- Add selected products to the shopping cart.

### 5. 🛒 Shopping Cart & Checkout
- Add products to the cart.
- Review selected items before checkout.
- Complete orders through the checkout process.
- Organize selected products for efficient order placement.

### 6. 🧾 Order Management & Thermal Printing
- View and manage restaurant orders.
- Edit and delete orders.
- Update order status between Pending and Completed.
- Print order invoices using a compatible thermal printer.
